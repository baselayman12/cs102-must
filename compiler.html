1. الإدخال والإخراج وحساب المجموع

برنامج يستقبل رقمين من المستخدم ويقوم بجمعها وطباعة الناتج النهائي.

#include <iostream> using namespace std; int main() { int a, b; cout << "Enter two numbers: "; cin >> a >> b; cout << "Sum = " << (a + b) << endl; return 0; }
2. مصفوفة وحلقة For Loop

تخزين درجات 5 طلاب وحساب المتوسط الحسابي (Average) باستخدام Loop.

#include <iostream> using namespace std; int main() { int scores[5] = {80, 90, 85, 95, 75}; int sum = 0; for(int i = 0; i < 5; i++) { sum += scores[i]; } cout << "Average = " << (sum / 5.0) << endl; return 0; }
3. المؤشرات (Pointers)

الوصول لعنوان المتغير وتعديل قيمته عبر الـ Pointer بواسطة Dereferencing.

#include <iostream> using namespace std; int main() { int x = 20; int* ptr = &x; cout << "Original x: " << x << endl; *ptr = 50; // تعديل القيمة عبر المؤشر cout << "Modified x: " << x << endl; return 0; }
4. كائن وفئة (OOP Class & Object)

إنشاء فئة Student مع بيانات الطالب ودالة طباعة المعلومات Constructor.

#include <iostream> using namespace std; class Student { public: string name; int id; Student(string n, int i) { name = n; id = i; } void printInfo() { cout << "Student: " << name << ", ID: " << id << endl; } }; int main() { Student s1("Ahmed", 102); s1.printInfo(); return 0; }
