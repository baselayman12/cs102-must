# المنصة التعليمية لمادة CS 102 - جامعة MUST 🎓

منصة تعليمية متكاملة لدعم طلاب الفرقة الأولى بكلية تكنولوجيا المعلومات بجامعة مصر للعلوم والتكنولوجيا (MUST) في مادة **CS 102 (برمجة الحاسب وهيكلة الكائنات OOP بالـ C++)**.

## 🌟 مميزات المنصة
- **المحاضرات والملخصات:** تحميل مباشر لملفات الـ PDF وسلايدات السكاشن ومشاهدة الشروحات.
- **البحث الفوري:** فلترة ذكية وسريعة للدروس والسكاشن.
- **بنك الكويزات التفاعلية:** اختبارات شاملة مع تصحيح وتحليل تفصيلي فوري.
- **مرجع الأساسيات:** مراجعة مكثفة لأهم مفاهيم لغة C++ مع ميزة نسخ الأكواد بضغطة زر.
- **منصة البرمجة والمساعد الذكي:** كتابة واختبار الأكواد مع محاكي ذكي مدعوم بالذكاء الاصطناعي لتحليل الأخطاء وشرحها.
- **تصميم عصري ومتجاوب بالكامل:** يعمل بسلاسة على أجهزة الكمبيوتر، الأجهزة اللوحية، والهواتف الذكية مع نظام Dark Glassmorphism الفاخر.
