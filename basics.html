أساسيات لغة C++ المقررة

ملخص سريع لأهم المفاهيم الأساسية: جمل الإدخال والإخراج، المصفوفات، والمؤشرات مع أمثلة توضيحية.

1. جملة الإخراج (cout)

تُستخدم طباعة النصوص والبيانات على الشاشة باستخدام المعامل `<<` (Insertion Operator) وتتطلب تضمين المكتبة `#include `.

// مثال على طباعة نص ومتغير int age = 19; cout << "Hello, MUST IT Students!" << endl; cout << "Your age is: " << age;

2. جملة الإدخال (cin)

تُستخدم لاستقبال البيانات والمُدخلات من المستخدم وتخزينها داخل متغيرات باستخدام المعامل `>>` (Extraction Operator).

// مثال على إدخال رقم من المستخدم int id; cout << "Enter your ID: "; cin >> id;

3. المصفوفات (Arrays)

المصفوفة هي مجموعة من عناصر متتالية في الذاكرة من نفس نوع البيانات. يبدأ الترقيم (Index) دائماً من **0**.

// تعريف مصفوفة بها 3 عناصر وطباعة العنصر الأول int grades[3] = {90, 85, 95}; cout << "First Grade: " << grades[0]; // Outputs 90

4. المؤشرات (Pointers)

المؤشر هو متغير خاص يقوم بتخزين **عنوان في الذاكرة (Memory Address)** لمتغير آخر. يُرمز له بالرمز `*` ونحصل على عنوان المتغير باستخدام `&`.

// تعريف متغير ومؤشر يشير إلى عنوانه int num = 10; int* ptr = # // ptr يحمل عنوان num cout << "Address: " << ptr; // يطبع عنوان الذاكرة cout << "Value: " << *ptr; // يطبع القيمة 10 (Dereferencing)
