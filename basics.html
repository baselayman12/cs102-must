تبسيط مفاهيم منهج CS 102 خطوة بخطوة بأمثلة برمجية توضح الفكرة بدون تعقيد.

1. ما هي الـ Object-Oriented Programming (OOP)؟

بدل ما بنكتب الكود كله في سطر واحد ورا بعضه (Procedural)، بنقسم البرنامج لـ Objects (كائنات) محاكية للواقع. كل كائن ليه خصائص (Attributes) وأفعال بيعملها (Methods).

💡 مثال من الواقع: الـ Class هو الرسم الهندسي للسيارة (Blueprint)، والـ Object هو العربية الحقيقية اللي بتصنعها وتسوقها من الرسمة دي.

بناء الكلاس وإنشاء الأوبجيكت (Class & Object)

01_class_object.cpp 
#include <iostream>
using namespace std;

// 1. تعريف الكلاس (النموذج)
class Car {
public:
    string brand;  // Attribute (خاصية)
    int speed;      // Attribute (خاصية)

    // Method (دالة بتنفذ فعل معين)
    void drive() {
        cout << brand << " is driving at " << speed << " km/h!" << endl;
    }
};

int main() {
    // 2. إنشاء Object من الكلاس
    Car myCar;
    myCar.brand = "BMW";
    myCar.speed = 220;
    
    // 3. استدعاء الدالة
    myCar.drive(); 

    return 0;
}

محددات الوصول (Access Modifiers)

بتحدد مين يقدر يوصل لبيانات الكلاس:

  • Public: متاح للجميع من داخل وخارج الكلاس.
  • Private: محمية، متقدرش تتعدل غير جوة الكلاس نفسه (أساس الـ Encapsulation).

المشيد (Constructor)

دالة خاصة بتشتغل تلقائياً أول ما تعمل Object جديد. اسمها بيكون نفس اسم الكلاس بالضبط ومفيهاش Return Type، وفائدتها إعطاء قيم أولية للبيانات.

مفهوم الـ Encapsulation (Setters & Getters)

02_encapsulation.cpp 
#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance; // الرصيد مخفي لحمايته

public:
    // Constructor
    BankAccount(double initialBalance) {
        balance = initialBalance;
    }

    // Setter: دالة لتعديل الرصيد بأمان
    void deposit(double amount) {
        if (amount > 0) balance += amount;
    }

    // Getter: دالة لقراءة الرصيد
    double getBalance() {
        return balance;
    }
};

int main() {
    BankAccount account(1000);
    account.deposit(500);
    cout << "Balance: $" << account.getBalance(); // Output: 1500
    return 0;
}
