أساسيات لغة C++ المقررة

دليل كامل ومرتب للمفاهيم البرمجية الأساسية المطلوبة هذا الترم مع أمثلة كود مبسطة وشرح عملي.

1. الإدخال والإخراج (cin / cout)

أساس التعامل مع المستخدم في C++. نستخدم `cout` مع المعامل `<<` لطباعة البيانات، ونستخدم `cin` مع المعامل `>>` لاستقبال البيانات وتخزينها في المتغيرات.

int age; cout << "Enter your age: "; // إخراج cin >> age; // إدخال cout << "Your age is: " << age;

2. المعاملات الحسابية والزيادة (x++, x += 1)

تُستخدم لزيادة قيمة المتغير، وهناك تكافؤ في المعنى بين الطرق لكن بفرق بسيط في آلية التنفيذ:

  • x++ أو x += 1 أو x = x + 1 : كلها تقوم بزيادة قيمة x بمقدار 1.
  • الفرق بين Post-increment و Compound Assignment:
    • `x++` تستخدم قيمة x الحالية أولاً في السطر ثم تزود 1.
    • `x += 5` تزيد قيمة x بأي قيمة تحددها (مثلاً 5) اختصاراً لـ `x = x + 5`.
int x = 5; x++; // x أصبحت 6 x += 4; // x أصبحت 10 (اختصار لـ x = x + 4)

3. المصفوفات (Arrays)

طريقة لتخزين مجموعة عناصر متتالية من نفس نوع البيانات تحت اسم واحد في الذاكرة. يبدأ الترقيم (Index) دائماً من 0.

int grades[3] = {90, 85, 95}; // مصفوفة من 3 أرقام cout << grades[0]; // يطبع العنصر الأول (90) grades[1] = 88; // تعديل العنصر الثاني إلى 88

4. المؤشرات (Pointers)

المؤشر هو متغير يخزن عنوان متغير آخر في الذاكرة بدلاً من قيمته.
• نستخدم الرمز `&` (Address-of) لجلب عنوان المتغير.
• نستخدم الرمز `*` لإنشاء المؤشر أو للوصول للقيمة المخزنة في العنوان (Dereferencing).

int num = 10; int* ptr = &num; // ptr يخزن عنوان num cout << ptr; // يطبع عنوان الذاكرة (Hexadecimal) cout << *ptr; // يطبع القيمة نفسها (10)

5. التمرير للدوال (Call by Value vs Call by Reference)

عند إرسال متغيرات إلى دالة (Function)، هناك طريقتان رئيسيتان للتعامل معها:

  • Call by Value (التمرير بالقيمة): تُرسل نسخة من قيمة المتغير. أي تعديل داخل الدالة لا يؤثر على المتغير الأصلي.
  • Call by Reference (التمرير بالمرجع): نستخدم `&` في تعريف الدالة لإرسال عنوان المتغير نفسه. أي تعديل داخل الدالة يُعدّل فوراً على المتغير الأصلي.
// 1. Call by Value void addVal(int x) { x += 10; } // لا يغير المتغير الأصلي // 2. Call by Reference void addRef(int &x) { x += 10; } // يغير المتغير الأصلي مباشرة
